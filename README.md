# 28 видеоэффектов для рилс — одной командой

Скилл `/effects` для нейросети-ассистента. Прикрепляешь вертикальное видео, где ты говоришь в камеру, пишешь команду — и получаешь готовый монтаж в 1080×1920. Зелёный экран не нужен: нейросеть сама находит тебя в каждом кадре.

```
/effects lock-screen
/effects list
```

## Установка

**Способ 1 — прямо в приложении.** Скачай [effects-skill.zip](https://github.com/maridurmanova/ai-video-effects/raw/main/effects-skill.zip), открой Настройки → Скиллы → «Добавить скилл» и выбери архив. В новом чате прикрепи видео и напиши `/effects text-behind`.

**Способ 2 — на компьютере, в режиме кода.** Нажми «Code» → «Download ZIP», распакуй, переименуй папку в `effects` и положи в `~/.claude/skills/` (на Windows — `%USERPROFILE%\.claude\skills\`). Потом попроси ассистента: «Подготовь к работе скилл effects: поставь всё нужное, включая ffmpeg, и проверь /effects list».

Если у тебя стояли прошлые наборы `effects` или `effects2`, удали их папки: этот набор включает всё.
